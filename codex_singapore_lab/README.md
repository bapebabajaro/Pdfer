# Codex Singapore Lab

Isolerad arbetsyta for Singapore/Stella-fragor. Denna mapp ar skapad for att kunna experimentera, analysera och producera forslag utan att andra Pdfer-, stellaworkbook- eller solofeedback-filer andras.

## Regel

Inga befintliga dokument utanfor `codex_singapore_lab/` ska andras i detta arbetsflode. Material har far bara flyttas in i riktiga projektfiler efter separat beslut.

## Syfte

Malet ar att skapa en reproducerbar metod for Singapore-uppgifter som inte tappar bort sig mellan:

- kallfraga
- Stella-koppling
- formatklassificering
- visual
- distraktorer
- construction note
- appintegration
- visuell verifiering

## Struktur

- `protocol/production_protocol.md` - praktiskt protokoll steg for steg.
- `templates/question_work_order.md` - mall som maste fyllas innan produktion.
- `gold_standard/` - forsta referensexempel och specs.
- `tools/` - lokala hjalpskript for kontroll.
- `audits/current_findings.md` - nulagesrisker hittade vid inlasning.
