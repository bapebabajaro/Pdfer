# Vatten som lösningsmedel

Tre elever testar om olika ämnen löser sig i vatten.

| Alternativ | Salt | Socker | Olja |
|---|---|---|---|
| A | löser sig | löser sig | löser sig |
| B | löser sig | löser sig | löser sig inte |
| C | löser sig inte | löser sig | löser sig inte |
| D | löser sig | löser sig inte | löser sig inte |

Vilken rad stämmer bäst?

- A) A
- B) B
- C) C
- D) D

**Rätt svar:** B
